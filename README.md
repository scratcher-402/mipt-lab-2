# Лабораторная работа №2

# Описание
`preparation.c` - здесь моделируются данные эксперимента и накладывается шум. Характерное время распада определяется как константа в функции `experiment`.

`processing.c` - здесь экспериментальные данные аппроксимируются линейной и экспоненциальной функцией.

`print.c` - функция вывода данных эксперимента для отладки.
